# Bouncing balls — current user preferences

Updated from feedback, 2026-10-31.

- Beads must be very bright and clearly stand out from the background; avoid dim metal with tiny white glints over dark bodies.
- Background and dais must have visibly different colors. Never use nearly matching blue-grey for both again.
- Dais should only slightly exceed the bead footprint: a narrow containing rim, not a wide empty platform. Current bead footprint radius is approximately 3.061; target dais radius 3.16.
- Background should be lighter than black, quiet and free from distracting scenery.
- Glossy metallic beads; warm radial colors; glossy glass dais.
- Shadows must respond to geometry, height, lighting and contact: no static dark disc. Inspect multiple phases for any future animation.
- Preserve tight sunflower packing and the current approved wave/bounce structure. Initial internal black gaps should be visually filled.
- Current scope: adjust Blender scene and deliver ONE still image for scoring. Do not render another video until the user requests it.
- Preserve earlier outputs as iterations.
